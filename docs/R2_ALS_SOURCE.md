# Private ALS implementation and comparison scope

The two profiles are parameter migrations from [Chien et al. (2021), official supplement](https://proceedings.mlr.press/v139/chien21a/chien21a-supp.pdf), Algorithm 2 / Appendix D.1 / Table 4, implicit ML-20M epsilon=1 and 5 columns. L1/L5 label those source columns, not the present budget. Both use epsilon=2.193078238018666, delta=1e-5, and both are reported. This is an original reimplementation aligned with the author practice branch at [fixed commit f14e9a45dbcc0e8b3cb714a7984c3cefe7660de3](https://github.com/google-research/google-research/tree/f14e9a45dbcc0e8b3cb714a7984c3cefe7660de3/dp_alternating_minimization); no third-party code is vendored. It is not a certified 2021 release reproduction or a tuned optimum.

Rank32; L1 uses one sweep, gravity2, beta.05; L5 uses three sweeps, gravity.6, beta.1. Both use k 60, radius1 and ridge.5. Two count releases have raw standard deviation100, so the preprocessing interface receives100/sqrt(60). Three independent training channels use the frozen profile scales 22.314001958810554 or38.64898511285133. The second count is still charged although regularization exponents are zero.

Full user frequent histories feed the local solve. Only item sufficient statistics use the permanent private-count tail cap. Private user factors are clipped. Full iid Gram noise is symmetrized; local/shared PSD projections are separate and precede ridge/gravity. This gives off-diagonal variance s^2/2, unlike the original paper's upper-triangle iid copy convention. No whitening is applied, consistent with the practice branch. Binary implicit inputs use center=false (official notebook cell 15 and supplement D.1); this is not omission of a required explicit-rating mean. Floor(beta*M), frequency regularization exponents0 and noisy filtering are the declared branch. The notebook's other settings, including exact_split=true/rank 64, are not reproduced.

Rare rows are zero-filled in the original complete public catalog. Final evaluation users are exact unclipped train-only local projections. All original train interactions are masked; Recall uses the complete target count, rather than the paper's capped denominator. Exact score ties use ascending original item ID. Public fixed slots are retained even with empty histories.

Each matched arm shares one realized private preprocessing and initialization with its private arm and removes only training noise. Their difference is conditional on this preprocessing, not the full cost of count noise/filtering/capping. The matched output is not DP. The two methods have different objectives/ranks/training horizons and matched controls; Table 9 therefore shows absolute utility as well as paired losses.

All72 models/36 pairs are reported. ALS has 9 pairs per dataset/profile, P-NSMF only 3 pairs per dataset from 12 specified factor-saving states. Shared numeric labels across methods do not create common noise. No cross-method paired CI or ten-seed interval is inferred. Coverage, zero factors and tie diagnostics are in metrics.csv. Low scores do not identify preprocessing/configuration/data/method causal contributions or establish a universal DP limit.


## Bounded target task validation extension

The original two configurations remain archived unchanged. The bounded extension considers six prespecified candidates per task, selects one by equal-copy validation NDCG20, and tests at separate seeds; it is not an optimum claim. See [S2.3](R2_TECHNICAL_DETAILS.md#s23-bounded-validation-selection-and-complete-accounting). Netflix was outside this study's initial two-task ALS comparison; no source-paper dataset restriction or unverified budget/resource rationale is asserted.

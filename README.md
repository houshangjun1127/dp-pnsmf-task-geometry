# Task Geometry Audit for User-Level DP Federated Recommendation

This repository contains the minimum computational materials needed to inspect and rerun the analyses reported in the associated study, including implementation code, frozen configurations, environment specifications, tests, and machine-readable result summaries.

## Unreleased R2 candidate additions

This candidate adds the complete two-profile Private ALS comparison: 72 models/36 pairs, portable frozen protocol/random streams, full event ledgers, stable full-catalog evaluation, 12 identified P-NSMF reference states and Table 9 generation. Both literature parameter migrations share epsilon 2.193078238018666/delta1e-5. The old DPALS-style stress test is retained only as history; its former same-budget accounting was incomplete and is superseded as current baseline evidence. See [corrections](docs/R2_CORRECTIONS.md), [implementation sources](docs/R2_ALS_SOURCE.md) and [trusted-central privacy model](docs/R2_PRIVACY_MODEL.md).

Check all reported summaries and budgets without data:

```text
python -m scripts.recompute_r2_tables --output-dir NEW_R2_CHECK_DIRECTORY
python -m pytest -q
```

Full rerunning commands are in REPRODUCIBILITY.md; benchmark data and factors are excluded. This is a reproducible public-seed research simulation, not a protected production release. The new comparison supports fixed-copy operating-point descriptions, not competitive optimality or general DP impossibility. All configurations and unfavorable results remain included.

Per-copy descriptive summaries, the four-group overview and Table 9 are generated by the no-data command rather than stored as redundant result files. Complete model metrics and all pair/cross-method rows remain archived.

No new release version/date/DOI is assigned by this candidate. Existing CITATION.cff describes historical software 0.3.0 metadata; it must be finalized for any new publication. The associated revision title is currently “Released-Query Diagnostics and Matched Evaluation in Full-Catalog User-Level Differentially Private Federated Recommendation”, subject to final manuscript confirmation. Historical 0.3.0 metadata and tags are retained.
